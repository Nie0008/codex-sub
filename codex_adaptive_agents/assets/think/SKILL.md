# 思维方法

围绕当前问题选择能补实际缺口的方法，保留用户目标、专业约束和已有证据。方法用于产生新假设、反例、候选或检查，不保证结论正确；来源、数据、测试和真实产物决定哪些判断成立。

模式与方法是可调整的起点，允许组合、跳过、改变顺序、替换或采用清单外的合适方法。用户明确指定的流程与专业验收要求仍保留；不以执行了多少方法衡量质量。

## 按缺口选择

| 迹象 | 按需读取 |
| --- | --- |
| 被既有解法锁住、事实与假设混杂、直觉没有证据 | [拆假设与核对证据](references/assumptions.md)：第一性原理、反向与反直觉检验、可证伪 |
| 只看到成功样本、比例没有分母、比较对象不清 | 同一参考中的选择偏差、基础率与因果/反事实分析 |
| 多个方案难取舍、沿用旧路径、可逆性或关键参数未明确 | [设计与决策](references/decisions.md)：旋转门、单向门/双向门、事前验尸、敏感性分析 |
| 需要判断下一步做什么验证、产物可能自证正确、主要反例未检查 | [执行与验证](references/verification.md)：对抗性分析、独立复现与最小验证试验 |

从当前最有帮助的方法起步，按发现调整，数量随实际缺口确定。已能直接计算或查明的事实，用实际工具解决。

## 使用方式

把方法落在具体材料上，区分观察与假设。探索和脑暴阶段可以提出类比、未经验证的设想与不完整方案；筛选方案、形成事实结论或行动依据时，再核对重要前提及来源、反例、试验或可核查产物。清楚标明已核验、条件成立时可行和仍未知的部分；必要时给出下一项最能区分解释的检查。

第一性原理需要检验所谓“基本事实”；反直觉不等于正确；偏差名称不能代替分母与选样机制；换负责人视角不能虚构新负责人知识。可逆性分析不扩大执行授权。没有原始材料或测量时保留边界，不能靠多种方法或多个模型的一致意见补出事实。

按用户用途交付，不强制展示全部思考过程或固定报告格式。方法若只增加措辞、没有新增有用解释、假设、证据、选项或可检验判断，就停止扩展。

本 Skill 可以由当前 Agent 直接使用，不要求派发子代理。需要多方执行或独立验证时，才结合现有 sub；人数、执行通道和方法不相互绑定。已有专业 Skill 继续负责领域知识与真实执行。
