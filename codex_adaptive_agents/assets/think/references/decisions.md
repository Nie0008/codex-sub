# 设计与决策

这些方法帮助明确改变方向、试验和选择的条件。它们不扩大授权，不凭空产生未知成本、用户偏好或概率。

## 旋转门与继任者视角

适用：继续投入的主要理由是过去投入、身份或维护旧决定。

假设新负责人拥有相同目标、信息、资源与现实义务，只是不需要为旧决定辩护。比较他会保留、停止、改变什么；区分不可追回的过去投入与仍会发生的切换成本。核对差异依据，提出有价值且可恢复的第一步。产物是方向差异、保留理由、未来代价与待查证据。

新负责人不自动更聪明，不能赋予他未知信息、免除合同或推翻需求。[Gary Klein 本人文章](https://www.psychologytoday.com/us/blog/seeing-what-others-dont/201309/mind-stretchers-1)称此为 revolving door test 并归于 Grove；本次未直接核实 Grove 原著是否使用这个名称。这是实践视角，未验证当前 LLM 的质量增益。

## 单向门与双向门

适用：决定被一律慎重审议，或重大后果被当成“先试再说”。

明确具体动作及对象：错了以后，谁能在多久内、用什么成本恢复到什么状态？检查数据、依赖者、外部传播和承诺的残留影响。把混合决定拆为可试与不可恢复部分；可试部分限定范围、观察窗口和回退条件，重大不可逆部分补关键证据。产物是可逆性依据与可执行的回退检查。

有 Git 不代表数据库或外部影响可恢复，可逆也不等于已获授权。[Bezos 2015 股东信](https://ir.aboutamazon.com/files/doc_financials/annual/2015-Letter-to-Shareholders.PDF)是一手管理原则，非效果试验。它问“错了能否恢复”；上面的旋转门问“摆脱旧承诺后该改变什么”，不要混用。

## 事前验尸

适用：方案只有顺利路径，风险全是“时间不足、质量不佳”等泛词。

指定未来时点与可观察的失败结果，暂时设定已发生。写几条“条件或事件→中间影响→最终失败”的具体路径，区分已有迹象与假设；为关键路径补早期信号、预防动作和触发后的响应。产物是能观察和处理的失败路径，不能只有虚构故事。

想得出不代表概率高，也不把失败设定当成必败预测。[Klein 官方说明](https://www.gary-klein.com/premortem)是方法来源；[1989 prospective hindsight 原研究](https://www.researchgate.net/publication/227768493_Back_to_the_future_Temporal_perspective_in_the_explanation_of_events)未测真实项目成功率，不将流传的“30%”写成项目成功率提升。当前提示效果仍待测。

## 敏感性分析

适用：推荐依赖薄弱参数、权重或成本假设。

给少数关键输入列有依据的范围与关系，用实际式子、表格或代码重算。简单模型找翻转阈值；有交互或非线性时检查合理组合。指出检验范围内是否稳定，优先补影响大、接近临界点的资料。产物是可复算结果、范围来源与翻转条件。

不任意取 ±10%，不把情境当概率，也不以局部稳定称全局稳健。[Saltelli 等原始研究，欧盟 JRC](https://publications.jrc.ec.europa.eu/repository/handle/JRC114437)指出单变量扫描遗漏输入空间的问题；小任务不必因此引入完整全局分析框架。
