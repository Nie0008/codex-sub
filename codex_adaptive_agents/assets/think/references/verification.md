# 执行与验证

核验当前承诺需要的证据。方法名、审查人数、模型自评或一致意见都不替代来源、计算、运行与目标读者判断。

## 对抗性分析与红队

适用：只验证成功路径，关键承诺可能被异常输入、对手或误用击穿。

明确真实相关参与者或异常环境的目标、信息与能力，缺资料的部分标假设。在这些能力内构造输入或动作序列，优先检验关键前提、来源、边界和验收条件。在已有授权与隔离范围内复现，留下输入、预期、实际行为和影响。无法实测的保留为具体风险假设。

不赋予对手无限能力，不把换角色自述当独立专家意见，不用无影响的挑刺淹没关键问题。[CIA 原始手册](https://www.cia.gov/resources/csi/static/Tradecraft-Primer-apr09.pdf)提供参与者视角分析的实践依据。[Perez 等原论文](https://arxiv.org/abs/2202.03286)实际生成输入并测试目标 LM，支持模型辅助找用例，不能证明角色模拟已完成核验。

## 独立复算、复现与覆盖核查

适用：计算、实现或结论由同一份产物自证正确，需要另一条证据路径。

固定目标、原始材料、版本、环境和口径。推导数值时先独立从材料计算，再比较；审查实际产物时提供产物及验收依据，另设计边界用例或回查来源。区分重复同一代码得到一致结果、独立方法算到相同结果、以及新数据支持同一主张。分歧定位到输入、口径、过程或证据，不能投票消除。

产物是可重算过程、可运行检查或来源回执，以及已覆盖／未覆盖部分。相同错误代码重复运行仍可能一致；不同模型也可能共享错误。验证者只写自己的报告、测试或候选；修复默认交回原共享产物负责人，明确阶段交接且原写入停止后也可移交。当前 Agent 可直接做检查，需要独立上下文或并行覆盖时再结合 sub。

[美国国家科学院 2019 报告](https://www.nationalacademies.org/read/25303/chapter/3)区分同数据同计算的 reproducibility 与新数据研究的 replicability，并说明成功复现不保证原结论正确。这是证据与科学实践依据，未证明某种多 Agent 配置普遍更优。

## 最小验证试验

适用：准备大量实现，但一个关键未知尚未验证；演示或讨论代替真实目标行为。

挑会改变下一步的未知，先写假设、对象和继续／放弃／结果不足的判据。用最少工作触及真实目标：技术可行性做运行探针，操作可用性做真实任务，付费需求核对报价、付款和交付，效果比较设计合适对照。运行后保留原始观察、分母、时间、费用与范围，按预设判据行动。

产物是短试验记录与实际结果。点赞、口头喜欢、自制样例或模型模拟不证明付费需求；小样本和弱对照不能装成因果证据。可以复用现有资产与人工处理，不先建整套系统。[Ries 原文](https://www.startuplessonslearned.com/2009/08/minimum-viable-product-guide.html)解释少量工作取得客户学习；[Kohavi 等受控实验原论文](https://ai.stanford.edu/~ronnyk/GuideControlledExperiments.pdf)给出实验条件。设计好不等于已经运行或有效。
